# 어디개? (Where Woof) 🐾

거리뷰 풍경만 보고 어디인지 지도에 찍는 위치 맞히기 게임이에요.
각자 고른 강아지가 찍은 곳에서 정답 지점(🦴)까지 달려가고, **먼저 도착한 강아지가 이겨요.**

## 게임 모드

- **📍 위치 맞히기**: 서울 / 대한민국 / 세계 도시 중 한 곳에서 문제가 나와요. 가깝게 찍을수록 유리하지만, 강아지마다 컨디션이 달라서 역전도 일어나요.
- **🌏 어디 나라개?**: 세계 87개 나라 중 어디인지 지도에서 골라요.
  - 정답 나라 5점 · 국경을 맞댄 옆나라 3점 · 같은 대륙 2점
  - 정답자가 없으면 가장 가까운 나라를 고른 사람이 최소 1점

## 특징

- 강아지 10종 (시바, 진돗개, 말티즈, 푸들, 허스키, 리트리버, 웰시코기, 닥스훈트, 비글, 불독)
- 견종마다 다른 짖는 소리와 발자국
- 1~6명이 한 기기에서 돌아가며 플레이
- 제한 시간(30초 / 60초 / 120초 / 없음)이 끝나면 거리뷰를 가리고 10초를 더 줘요

## 실행 방법

1. `index.html`을 브라우저로 열어요. (GitHub Pages로 배포해도 돼요)
2. 시작 화면 아래 **Google Maps API 키** 칸에 키를 넣어요.
   - Google Cloud 콘솔에서 **Maps JavaScript API**를 켜 두면 돼요.
   - 키는 각자의 브라우저에만 저장되고, 이 저장소에는 들어 있지 않아요.
   - 키에는 **웹사이트 제한**(이 게임을 여는 주소)을 걸어 두는 걸 추천해요.

## 사용한 데이터

- 서울 행정구역 경계: 통계청 경계 데이터 ([southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps))
- 세계 나라 경계: [Natural Earth](https://www.naturalearthdata.com/) (퍼블릭 도메인)
